# PLAY YOUR LIFE

Мобильное веб-приложение для личного развития с геймификацией.

Текущая версия приложения — **0.6.3**. Актуальные исходники опубликованного сайта находятся в `main`. [Состав версии](CHANGELOG.md).

Меню и мобильный подвал оформлены по последним образцам: чёткая корона PLAY YOUR LIFE и подробные иллюстрации города. Вход, загрузка и иконки приложения используют присланный логотип YOUR LIFE. [Размеры, проверка и обновление ярлыка](docs/BRAND.md).

## Город сфер жизни

SPORT — первый настоящий 3D Room Engine на Three.js, React Three Fiber и drei: камера, пустой спортзал, шесть объёмных моделей-заготовок, магазин, инвентарь и расстановка по сетке с проверкой пересечений. [Открыть отдельный тестовый прототип](https://vodolivan95.github.io/play-your-life/?room-demo=sport). Прогресс прототипа отделён от личной игры. [Описание и нужные GLB-ассеты](docs/ROOM-3D.md).

Из карты города можно войти в SPORT или перейти к сферам и квестам. Остальные восемь 3D-интерьеров готовятся; старые схематичные комнаты скрыты. Существующие сохранения города поддерживаются. [Подробнее](docs/CITY.md).

## Главная страница

Главная по обновлённому образцу: приветствие, прогресс игрока, девять зданий сфер, квесты и расписание дня, выбранная награда, серия активности и прогноз Яндекса для Люберец. Логотип и город в меню на всех страницах. Логика будущих задач и привычек TickTick зафиксирована без подключения новой синхронизации. [Подробнее](docs/HOME.md).

## Текущий этап

8 октября 2026 пользователь проверил и принял страницу цели с баннером, шестью вкладками, раскрывающейся картой этапов, наградами, мотивацией и историей. Каждый этап открывается по собственному адресу через «Продолжить»; внутри доступны задачи, календарь, сроки, заметки и управление. Используются существующие данные и правила наград. Максимум уровня игрока и всех сфер — **100**, накопленный XP сохраняется. Функции, изменённые файлы и проверки: [docs/GOAL-WORKSPACE.md](docs/GOAL-WORKSPACE.md).

Прогресс сохраняется локально; личная игра авторизованного пользователя использует существующую синхронизацию Firebase, офлайн-очередь и обработку конфликтов. Описание: [docs/FIREBASE.md](docs/FIREBASE.md). Проверки эмулятора не подтверждают вход в реальный аккаунт и работу производственной синхронизации.

В текущих исходниках хранится одна актуальная версия приложения. Старые документы версий и неиспользуемые изображения убраны; историю изменений можно просмотреть в GitHub. В профиле есть **Мой TickTick**: личный OAuth-вход, девять сопоставлений списков со сферами и настройки по аккаунту. Владелец сайта один раз публикует общий сервер, затем каждый пользователь подключает свой TickTick. [Пошаговая настройка](docs/TICKTICK-SETUP.md), [архитектура и границы обмена](docs/TICKTICK.md). Пока сервер не опубликован, живая синхронизация не подтверждена.

## Среда разработки

- Название окружения: **PLAY YOUR LIFE**.
- Репозиторий: [vodolivan95/play-your-life](https://github.com/vodolivan95/play-your-life).
- Основа: React, TypeScript и Vite.
- Инструменты: Node.js 24, npm и ESLint.
- Работа с телефона через GitHub Codespaces.
- Автоматическая проверка кода и сборки настроена в GitHub Actions.

## Запуск с телефона

1. Откройте [создание Codespace](https://github.com/codespaces/new?hide_repo_select=true&repo=1402045109).
2. Выберите ветку `main` и нажмите **Create codespace**.
3. Дождитесь завершения установки пакетов.
4. В терминале выполните:

   ```sh
   npm run dev
   ```

5. Во вкладке **Ports** откройте ссылку порта **5173**. Оставьте доступ **Private**.

После запуска откроется главный экран приложения.
Если кнопки не видны на телефоне, включите «Версия для ПК» в браузере.

## Команды

| Команда | Назначение |
| --- | --- |
| `npm run dev` | Запуск сервера разработки |
| `npm run check` | Проверка кода, TypeScript и сборки |
| `npm test` | Существующие проверки игровой логики и интеграций |
| `npm run test:goals-ui` | Проверка цели и этапов на компьютере, планшете и телефоне |
| `npm run build` | Создание сборки в папке dist |
| `npm run preview` | Просмотр готовой сборки |

Версии зависимостей закреплены в `package-lock.json`. Для установки используйте `npm ci`.

## Полезные файлы

- `src/` — интерфейс и игровая логика приложения.
- `.devcontainer/devcontainer.json` — настройки окружения PLAY YOUR LIFE.
- `.github/workflows/ci.yml` — автоматические проверки.
- [docs/SETUP.md](docs/SETUP.md) — инструкция по работе с телефона.

Для локальной проверки используйте `npm run check`.
Результаты автоматических проверок доступны во вкладке **Actions** репозитория.
После работы останавливайте Codespace на странице [GitHub Codespaces](https://github.com/codespaces).
