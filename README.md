# PLAY YOUR LIFE — V0.1

Мобильное веб-приложение для развития в реальной жизни. **Your Life. Your Game.**

## Что работает

- Главная: персонаж, уровень, XP, монеты, серия, главная цель, квесты и девять сфер.
- Квесты: создание, выбор сферы и сложности, выполнение, фильтры, удаление.
- Цели: создание, целевое значение, изменение прогресса, статус и одноразовая награда 100–500 XP.
- Сфера: уровень, XP, Life Score 0–9, коэффициент, цели, квесты и история изменений.
- Статистика: XP за последние семь дней, выполненные действия, серия, баланс Life Score и общий прогресс.
- Профиль: изменение имени, серии и переходы к дереву навыков и достижениям.
- Дерево навыков: девять веток, связи и узлы, открывающиеся на уровнях 1, 3 и 5.
- Достижения: первый квест, серия 7 дней, 1000 XP, Спорт уровня 5.
- Светлый адаптивный интерфейс с нижней навигацией на телефоне и боковой на desktop.

Первый запуск содержит демонстрационные данные: 2450 XP, две цели, четыре квеста и два дня серии. Их можно дополнять и изменять. Стартовый XP не входит в график новых действий. Уровень рассчитывается из XP; фиксированный пример уровня не используется.

## Игровые правила

- Micro / Simple / Medium / Hard / Very Hard дают 5 / 10 / 20 / 35 / 50 XP.
- Выполнить конкретный квест можно один раз. Награда одновременно увеличивает XP персонажа и сферы.
- Каждые 200 XP дают следующий уровень: `floor(XP / 200) + 1`.
- Монеты начисляются за квесты: минимум одна, далее `floor(XP / 5)`. Магазин пока отсутствует.
- Life Score: бонус равен росту над ранее достигнутым максимумом × коэффициент сферы. При первом росте это совпадает с формулой разницы оценок. Понижение и возврат к прежнему максимуму не позволяют повторно получать бонус; XP не отнимается.
- Коэффициенты: Здоровье 20, Спорт 15, Саморазвитие 12, Английский 15, Финансы 20, Совместные задачи 10, Вождение 8, Задачи 10, Досуг и хобби 8. Они вынесены в данные отдельно от UI.
- Серия считается по календарным дням устройства. Хотя бы один выполненный квест делает день активным. Пропуск дня обнуляет текущую серию.
- Награды серии: 3 / 7 / 14 / 30 / 100 / 365 дней → 10 / 30 / 50 / 100 / 300 / 1000 XP. Каждый порог награждается один раз в рамках серии. Множителей нет.
- Завершение цели награждается один раз, даже если впоследствии уменьшить и восстановить прогресс.

## Запуск

Node.js 24 и npm. После клонирования:

```sh
npm ci
npm run dev
```

Откройте порт 5173. Для работы с телефона используйте [GitHub Codespaces](https://github.com/codespaces/new?hide_repo_select=true&repo=1402045109), выбрав ветку с V0.1. Конфигурация окружения и GitHub Actions сохранены. Порт можно оставить Private. После работы остановите Codespace.

```sh
npm run test   # проверки игровой логики
npm run check  # ESLint, игровые проверки, TypeScript и сборка
npm run build # отдельная production-сборка
npm run preview
```

## Хранение и структура

Данные автоматически сохраняются в `localStorage` под ключом `play-your-life:v1`. Они принадлежат текущему браузеру и адресу сайта. Нет авторизации, сервера, синхронизации или базы данных. Очистка данных сайта удалит прогресс. Ошибка сохранения показывается в интерфейсе.

- `src/pages/` — экраны.
- `src/components/` — общие карточки, прогресс и строки квестов.
- `src/state/` — централизованное состояние и заменяемый `StorageAdapter`.
- `src/types/` — строгие типы.
- `src/data/` — демоданные, коэффициенты и награды.
- `src/engine/` — расчёты XP, уровней, наград и достижений.
- `src/utils/` — календарные даты и серия.
- `scripts-test.mjs` — проверки игровых инвариантов.

Переходы между экранами работают без перезагрузки. Иконки пока представлены emoji; внешний шрифт имеет системный fallback. Self-report действий и прогресса доверяет пользователю; это личный трекер, а не серверная система проверки.

## Проверено

ESLint, строгий TypeScript, production-сборка и автоматические проверки игровой логики. Проверки охватывают повторное выполнение квеста, общий и сферный XP, защиту Life Score и целей от повторных бонусов, награды серий, пропуск дня, границы уровней и сериализацию состояния.
