# PLAY YOUR LIFE

Мобильное веб-приложение для личного развития с геймификацией.

## Город сфер жизни

Добавлена отдельная вкладка с интерактивным городом: девять зданий для девяти сфер, текущие уровни и Life Score, переход в сферу по нажатию. [Подробнее](docs/CITY.md).

Правила и ограничения: [docs/V0.1.md](docs/V0.1.md).

## Среда разработки

- Название окружения: **PLAY YOUR LIFE**.
- Репозиторий: [vodolivan95/play-your-life](https://github.com/vodolivan95/play-your-life).
- Основа: React, TypeScript и Vite.
- Инструменты: Node.js 24, npm и ESLint.
- Работа с телефона через GitHub Codespaces.
- Автоматическая проверка кода и сборки настроена в GitHub Actions.

## Запуск с телефона

1. Откройте [создание Codespace](https://github.com/codespaces/new?hide_repo_select=true&repo=1402045109).
2. Выберите ветку `main` и нажмите **Create codespace**.
3. Дождитесь завершения установки пакетов.
4. В терминале выполните:

   ```sh
   npm run dev
   ```

5. Во вкладке **Ports** откройте ссылку порта **5173**. Оставьте доступ **Private**.

После запуска откроется главный экран приложения.
Если кнопки не видны на телефоне, включите «Версия для ПК» в браузере.

## Команды

| Команда | Назначение |
| --- | --- |
| `npm run dev` | Запуск сервера разработки |
| `npm run check` | Проверка кода, TypeScript и сборки |
| `npm run build` | Создание сборки в папке dist |
| `npm run preview` | Просмотр готовой сборки |

Версии зависимостей закреплены в `package-lock.json`. Для установки используйте `npm ci`.

## Полезные файлы

- `src/` — интерфейс и игровая логика приложения.
- `.devcontainer/devcontainer.json` — настройки окружения PLAY YOUR LIFE.
- `.github/workflows/ci.yml` — автоматические проверки.
- [docs/SETUP.md](docs/SETUP.md) — инструкция по работе с телефона.

Для локальной проверки используйте `npm run check`.
Результаты автоматических проверок доступны во вкладке **Actions** репозитория.
После работы останавливайте Codespace на странице [GitHub Codespaces](https://github.com/codespaces).

## GitHub Pages

Публикация настроена в `.github/workflows/pages.yml`: после изменения `main` сайт автоматически проходит проверки и обновляется.

Адрес после публикации: https://vodolivan95.github.io/play-your-life/

Один раз выберите **Settings → Pages → Source → GitHub Actions**. Подробные шаги: [docs/PAGES.md](docs/PAGES.md).
