# PLAY YOUR LIFE

Мобильное веб-приложение для личного развития с геймификацией.
Сейчас подготовлена только основа разработки. Функций и экранов пока нет.

## Окружение

React + TypeScript + Vite, Node.js 24, ESLint.
Конфигурация GitHub Codespaces называется **PLAY YOUR LIFE**.
Зависимости устанавливаются автоматически при создании Codespace.
GitHub Actions проверяет код и сборку при отправке изменений.

## Запуск с телефона

1. Откройте https://github.com/codespaces/new?hide_repo_select=true&repo=1402045109
2. Выберите ветку main и нажмите Create codespace.
3. Дождитесь завершения настройки окружения.
4. В терминале выполните `npm run dev`.
5. Откройте ссылку порта 5173 во вкладке Ports. Доступ к порту оставьте Private.

Пустая страница ожидаема: интерфейс пока не разработан.
Если элементы GitHub не видны, включите в браузере «Версия для ПК».

## Проверка и сборка

```sh
npm run check
npm run build
npm run preview
```

Для запуска вне Codespaces сначала выполните `npm install` на Node.js 24.
Первый запуск создаст package-lock.json: сохраните его в Git.
После этого устанавливайте зависимости командой `npm ci`.
