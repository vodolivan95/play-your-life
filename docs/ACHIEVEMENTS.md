# Достижения

Раздел «Достижения» показывает прогресс игрока по реальным данным `GameState` — нет ни одной награды,
которая не считалась бы по действительно хранимому состоянию игры.

## Источник дизайна

Полный дизайн (150 наград, 13 категорий, включая психологию «21–60–90 дней») был сначала собран как
прототип на холсте Claude Design: <https://claude.ai/artifact/XVUw5xVcAzaKujCED4eDxz>. Холст — только
прототип; в код перенесена часть, для которой в игре уже есть реальное отслеживаемое состояние (см.
«Что не перенесено» ниже).

## Реализация (версия 0.50.0)

- `src/game.ts`: тип `Achievement` (`category`, `tier`, `name`, `icon`, `description`, `unlocked(s)`,
  `progress(s)`, необязательный `insight`) и массив `achievements` — 92 достижения в 13 категориях:
  Первые шаги, Задачи, Привычки, Психология, Цели, Сферы жизни, Город, Дерево навыков, Серии, Профиль,
  Магазин, Мои итоги, Особые.
- `src/App.tsx`: страница «Достижения» группирует карточки по `category` (как `.section-heading` в
  других разделах) и показывает собственную эмодзи-иконку каждого достижения (`a.icon`) вместо общей
  иконки трофея.
- Психологические достижения («Если — то», «Дневник благодарности», «Три фокуса», «Закрытый гештальт»,
  «Отскок») читают реальные поля `MonthReview` (`ifThen`, `gratitude`, `focuses`, `plans`) и серии
  привычек (`currentStreak`/`bestStreak`) — те же данные, что уже показываются в «Моих итогах» и
  «Привычках».
- Привычная серия 21–60–90 дней (`bestHabitStreak`) — единая лестница достижений с пояснением смысла
  каждой вехи (`insight`), без выдуманных отдельных «серий задач» или «серий входа»: в игре нет
  отдельного счётчика на эти два понятия, оба используют один и тот же `activeDates`/`habits`.

## Что не перенесено с холста

Эти пункты макета не имеют соответствующего отслеживаемого состояния в игре и намеренно не реализованы
(вместо того чтобы притворяться достижениями, которые никогда не разблокируются):

- Описание, своя обложка и напоминание привычки — у `Habit` в коде этих полей ещё нет.
- Точная дата рождения, разовый снимок «777 XP», скрытая деталь на карте города — такие события не
  фиксируются.
- Приглашение друга, рейтинг игроков — в игре нет социальных функций.
- Задания мэра, настроение города — механики не реализованы (см. «Незавершённое» в `AGENTS.md`).
- Отдельный трекер использования мобильного приложения/APK — такой телеметрии нет.

Любой из этих пунктов можно добавить позже отдельным заданием, когда появится соответствующее состояние
игры.
