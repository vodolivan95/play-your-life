# Работа через ChatGPT, Codex и Claude

Один репозиторий `vodolivan95/play-your-life`, одна ветка `main`, общие правила в `AGENTS.md`.

## Обычный цикл задачи

1. **Идея → ТЗ.** Обсудите задачу в ChatGPT. Попросите оформить её по шаблону «Задача» и создайте Issue на GitHub. Поставьте метку `codex` или `claude`.
2. **Реализация.** Дайте ссылку на Issue нужному инструменту:
   - Codex: «Выполни Issue #N по правилам AGENTS.md».
   - Claude (claude.ai или Claude Code): «Выполни Issue #N по правилам AGENTS.md».
3. **PR.** Инструмент создаёт ветку `codex/…` или `claude/…` и открывает PR по шаблону.
4. **Ревью.** Попросите второй инструмент проверить PR: «Сделай ревью PR #N».
5. **Слияние.** Когда проверки в PR зелёные и ревью пройдено, нажмите **Merge** сами. GitHub Pages обновится автоматически.

## Как подключить репозиторий

- **ChatGPT:** Настройки → Подключённые приложения → GitHub, доступ к `play-your-life`. Тогда ChatGPT читает код и Issues.
- **Codex:** уже подключён к репозиторию.
- **Claude:** claude.ai → Settings → Connectors → GitHub. В проекте Claude «Play Your Life» хранится аудит и решения.

## Правила, которые важно помнить

- Две задачи в одних и тех же файлах одновременно не запускать (см. «Зоны файлов» в `AGENTS.md`).
- Решения фиксируются в Issue и PR — так их видят все инструменты, а не только тот чат, где они обсуждались.
- Ни один ИИ не сливает PR в `main` сам.
