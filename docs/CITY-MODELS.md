# Остров по визуальному референсу

Исправление предыдущего направления: однотипные прямоугольные здания и квадратная площадка заменены авторскими моделями тропического острова. Референс определяет расположение районов, светлые фасады, округлые террасы, стекло, озеленение и отличительные символы. Изображение не используется в качестве фона, billboard города или текстуры фасадов.

## Модели

`npm run city:models` создаёт настоящие бинарные GLB в `public/models/city/`. Сборка приложения запускает этот шаг автоматически, поэтому опубликованные assets воспроизводимы из исходников. `manifest.json` содержит размер, число треугольников и число batches каждой модели.

| Файл | Геометрия |
| --- | --- |
| health.glb | Два крыла с округлыми стеклянными фасадами, террасы, центральный портал, объёмное сердце, фонтан |
| english.glb | Языковая академия с объёмным глобусом, меридианами и параллелями, террасы и фонтан |
| sport.glb | Овальный стадион, открытая арена, беговые дорожки, ворота, знак гантели |
| driving.glb | Автошкола с синей аркой, припаркованной машиной, автодромом и конусами |
| finance.glb | Белый банк с золотыми колоннами, круглым знаком монеты и фонтаном |
| growth.glb | Округлая библиотека с объёмным знаком книг |
| together.glb | Дом общих дел с парными объёмными сердцами |
| tasks.glb | Мастерская планов с трёхмерным знаком выполненных задач |
| hobby.glb | Дом творчества с цветной скульптурой |
| island.glb | Неровный берег, скалы, пляж, арочные мосты, дороги, переходы, цветники, маяк и дальние холмы |
| palm.glb | Изогнутый ствол и отдельные изогнутые пальмовые листья |

Геометрия моделируется в Three.js в build-time и экспортируется через GLTFExporter. Сложные формы объединены по материалам, чтобы не отправлять каждый элемент фасада отдельным draw call. Это авторская геометрия проекта, без скачанных сторонних ресурсов или ассетов чужих игр.

## Сцена

GLB загружаются через `useGLTF` только при открытии города. Материалы экземпляров зданий клонируются для снега и ночной подсветки. На дорогах меняются roughness и цвет при увлажнении. Пальмы имеют умеренное движение от ветра; автомобили и парусник используют настоящие модели. В городе нет вторичного наложенного PNG-здания.

Планировка сохраняет девять районов: здоровье/спорт/знания, английский/финансы/общие дела, автошкола/планы/творчество. Здание SPORT остаётся входом в существующую RoomEngine. Магазин, монеты, инвентарь, placement и сохранения комнаты не изменены.

Камера показывает остров с верхней перспективой; на телефоне начальный ракурс приближён к левому ряду зданий, как в референсе. Кнопка «Весь остров» открывает общий вид. Телефон адаптирует FOV, остаётся возможность drag/pinch. Отражения стекла поддерживает компактное environment lighting без внешней HDR-загрузки. Погода и качество сохраняются.

## Границы результата

Модели повторяют архитектурные признаки и композицию референса, но не являются точной фотограмметрической реконструкцией. Для полного уровня детализации референса остаются работа с фактурами, более сложный ландшафт и разнообразие растений/жителей. NPC пока процедурные placeholders; предметы внутри SPORT сохраняют прежний статус DEV PLACEHOLDER. Оценивать результат нужно по скриншотам живой сцены, а не по приложенному арту.
