# Качество основного изображения города

Основное изображение и статические превью используют `src/assets/coastal-city-enhanced.webp`: восстановленные края, фактура и надписи, 1111×1415, WebP quality 98. Исходный JPEG 1005×1280 сохранён; изображения карточек и обложек квестов не заменяются произвольными зданиями. Это улучшение имеющегося визуала, а не настоящий 4K-исходник и не гарантия новых достоверных деталей.

Нормализованные координаты, девять зон входа, маршруты, игровой прогресс и UI-иконки не менялись. Вырезки для покачивания растений учитывают actual naturalWidth/naturalHeight, чтобы изображение большего размера не нарушало привязку локальных эффектов. Основная карта и баннеры используют один URL и кеш браузера. Старые файлы оставлены для отката.

Проверки: npm run check (lint, typecheck, build), npm test и браузерная проверка live-city на desktop и 360/390/412/430, включая движение, touch zoom, wheel, девять входов и возврат. Сильное увеличение всё ещё ограничено разрешением растрового изображения.
