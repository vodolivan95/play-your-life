# Финансы — личный учёт трат и доходов

Статус: реализовано 29 октября 2026 (версия 0.63.0), ручной ввод. Синхронизация с ZenMoney не начата.

## Что это и чем не является

Вкладка «Финансы» в левом меню (`budget` в коде, подпись «Финансы») — это учёт **реальных денег**: сколько потрачено и получено, по категориям, по месяцам и годам. Она не связана с игровой экономикой (лайфкоины, XP) и не связана с игровой сферой «Финансы» (`finance` в `spheres`/«Сферы жизни») — та сфера про игровые задачи и привычки на тему денег, здесь же — настоящий бюджет. Названия совпадают намеренно (так попросил Иван), коды разные.

## Данные

`src/finance.ts`:
- `FinanceTransaction` — `type: 'expense' | 'income'`, `amount` (рубли, положительное число), `categoryId`, `date` (`YYYY-MM-DD`), `note?`, `createdAt`, `source: 'manual' | 'zenmoney'` (сейчас всегда `'manual'`, задел под синхронизацию).
- `FinanceCategory` — `id`, `name`, `icon` (эмодзи), `type`. 19 стандартных категорий (`defaultFinanceCategories`) подобраны по образцу категорий ZenMoney (продукты, кафе и рестораны, транспорт, жильё и коммуналка, здоровье, одежда, развлечения, подписки и связь, образование, путешествия, подарки, семья, красота, товары для дома, прочее — для трат; зарплата, подработка, подарки и возвраты, прочее — для доходов). Игрок может добавить свою категорию на лету из формы добавления записи.
- Хранится в `GameState.financeTransactions`/`financeCategories` (оба поля опциональны, отсутствие = пусто). Валидация — `validFinanceTransactions`/`validFinanceCategories`, подключена в `stateValidation.ts`.
- **Лимит 6000 записей** (`MAX_FINANCE_TRANSACTIONS`): записи пока хранятся одним массивом в основном облачном документе Firestore (лимит документа — 1 МиБ). Для ручного ввода этого хватит очень надолго. Если позже подключится синхронизация с ZenMoney и записей станет на порядки больше, их нужно будет шардировать по месяцам так же, как `events` в `cloudSplit.ts` (`players/{uid}/history/{ГГГГ-ММ}`) — отдельная задача, не делать заранее без необходимости.

## Экран

`src/components/FinancePage.tsx`/`FinancePage.css`. Два режима (переключатель сверху):
- **Помесячно**: навигация стрелками по месяцам; три плитки (траты, доход, остаток), у трат — изменение в % к прошлому месяцу; разбивка трат по категориям (название, полоса доли, сумма, %); список всех операций месяца, новые сверху — тап по строке открывает её на редактирование, корзина удаляет.
- **По году**: выбор года из списка (годы, где есть хоть одна запись, плюс текущий); те же три плитки за год; столбчатый график трат по 12 месяцам (клик по столбцу переключает на этот месяц в режиме «Помесячно»); годовая разбивка по категориям.
- **Добавление/редактирование записи** — нижний лист (модальное окно): переключатель «Трата / Доход», сумма, дата, сетка категорий нужного типа с кнопкой «+ Своя» (имя + эмодзи), заметка. Валидация — те же правила, что в `finance.ts`; ошибка показывается уведомлением, запись не создаётся.

## Пункт меню

`src/navigation.ts` (`id: 'budget'`, label «Финансы»), иконка-кошелёк в `src/menuIcons.ts` (`MenuIconId`). В мобильной панели пункт открывается через «Ещё» (`src/components/MobileNav.tsx`, `moreIds`) — отдельного места в нижних пяти кнопках не выделено, как и для «Ключевые итоги»/«Магазин»/«Профиль».

## Синхронизация с ZenMoney — не реализована, следующий шаг

Иван ведёт реальный учёт расходов в приложении ZenMoney и хочет синхронизацию. У ZenMoney есть публичный HTTP API (`api.zenmoney.ru`, OAuth 2.0, чтение/запись через `POST /v8/diff/`; описание в вики `zenmoney/ZenPlugins`), но для него нужно зарегистрировать отдельный OAuth-клиент — по той же схеме, что уже сделана для TickTick: Cloudflare Worker-прокси (см. `integrations/ticktick/` как образец), секреты, маршрут авторизации, экран подключения в «Профиле» или здесь. Это отдельная, не начатая задача. Когда до неё дойдёт:
1. Регистрация OAuth-клиента ZenMoney (аккаунт разработчика, как `TickTick developer app` у Ивана).
2. Worker-прокси по образцу `play-your-life-ticktick`, хранение токена.
3. Сопоставление категорий ZenMoney ↔ `FinanceCategory` по имени/иконке (стандартный набор здесь подобран заранее именно для этого).
4. Импорт транзакций как `source: 'zenmoney'`, без перезаписи того, что игрок ввёл вручную.
5. Прежде чем тянуть большую историю — шардирование записей по месяцам (см. «Данные» выше), иначе основной документ быстро упрётся в лимит 1 МиБ.
