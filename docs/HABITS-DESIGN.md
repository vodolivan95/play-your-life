# Привычки — согласованный дизайн (холсты Claude Design)

Статус: **дизайн согласован 12 октября 2026, в игре не реализован**. Реализация — отдельное задание. Все цифры, названия привычек и награды на холстах — примеры, механика не утверждена.

## Холсты

- Браузерная версия: https://claude.ai/artifact/WuUFsivnrcKJDzJtpNTsw6 — «Привычки — экран» (с окном привычки по нажатию на строку) и «Новая привычка».
- Версия для телефона: https://claude.ai/artifact/W6vitNdxrBubACyu9RHBzg — «Привычки — список», «Привычка — подробно», «Новая привычка».

## Что согласовано

- Раздел «Привычки» (бывший «Квесты»); подпись «Маленькие шаги к большим переменам.»
- Сводка: кольцо «Сегодня n/N» (зелёный градиент), лучшая серия с огоньком-персонажем, процент за неделю.
- Список привычек: сфера, 7 дней точками, серия, круглая отметка за сегодня; нажатие на строку открывает окно привычки.
- Календарь с переключателем «Неделя / 2 недели / Месяц / 3 месяца» (точки цветом сферы, дни со всеми привычками зелёные).
- Окно привычки: отметка, серия, лучшая серия, месяц, награда XP, календарь привычки, расширенная статистика (90 дней: процент, пропуски, лучший день, в неделю, XP; столбики по дням недели и по неделям), расписание, напоминание, «Изменить», «В архив».
- «Новая привычка»: название, своя картинка вместо иконки, сфера, дни недели, напоминание, сложность и награда (лёгкая +5, средняя +10, сложная +15, тяжёлая +20 — примеры), описание «Для чего эта привычка» (до 200 символов).

## Не решено (нужен ответ Ивана перед реализацией)

- Сколько XP даёт привычка и растёт ли награда с серией; куда идёт XP (сфера привычки).
- Что с серией при пропуске: обнуление или «заморозка».
- Расписание: только ежедневные или по дням недели.
- Где хранить картинку привычки и описание (структура сохранений — через Issue, `src/stateValidation.ts`, `firestore.rules`).
- Огонёк-персонаж: на холсте свой рисунок; для игры нужен окончательный файл.
