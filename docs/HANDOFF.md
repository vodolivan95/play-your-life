## Как начать

```
git fetch origin main && git checkout main && git pull --ff-only origin main
git checkout -b codex/<задача>
```

Перед работой прочитать `AGENTS.md` (правила, зоны файлов, «Принятая версия»), `CHANGELOG.md` и `docs/` по своему разделу. Проверки: `npm run check`, `npm test`; UI-тесты (Playwright) идут в GitHub Actions. Версию поднимает последний PR перед выпуском: `package.json`, `package-lock.json`, `index.html`, `CHANGELOG.md`, `AGENTS.md`.

## На что обратить внимание

- Иван пишет коротко и просит двигаться самостоятельно; общение и документация на русском.
- Не реализовывать то, что не заказано. Макет согласуется на холсте до кода.
- Тёмная тема создаётся скриптом `scripts/build-dark-theme.mjs` (`npm run theme:dark`); новые страницы со своими стилями либо добавляются в его список, либо сами оформляют `:root[data-theme='light']`. См. `docs/THEME.md`.
- В окружении Claude нельзя запустить `npm`; проверка там — модульные тесты `node --experimental-strip-types --test tests/*.test.ts` и CI. Если у вас npm доступен, запускайте `npm run check` и `npm test` локально.
- Сборка и UI-тесты в CI могут идти несколько минут (`quests-ui` дольше всех).
- Иван может поручить слияние PR прямо — тогда слить после зелёного `Project checks`; иначе PR сливает он.
- Старые вертикальную карту подвала, прежнюю вкладку «Квесты» вместо «Привычек» и нарисованных человечков не возвращать (список в `AGENTS.md`).
