# Главная страница

Версия 0.8.0. Компонент — `src/components/HomeDashboard.tsx`, стили — `HomeDashboard.css`.

## Главный блок
Приветствие по времени суток, заголовок «Твоя жизнь в твоих руках», кнопка «Продолжить путь» (ведёт к задачам) и справа карточка «Главные квесты месяца».

## Главные квесты месяца
- Пользователь выбирает до трёх своих целей («Изменить выбор» → флажки → «Готово»).
- Прогресс берётся из самой цели; нажатие на квест открывает цели.
- Данные: `state.monthlyFocus = { month: 'ГГГГ-ММ', goalIds: [...] }`, логика — `src/monthlyFocus.ts`, проверка — `src/stateValidation.ts`, тесты — `tests/monthly-focus.test.ts`.
- Месяц считается по Москве. Выбор прошлого месяца не переносится: в новом месяце выбирают заново.
