# Ключевые итоги

Раздел под «Профилем» (пункт «Ключевые итоги», страницы `statistics` и `monthly`). Холст Claude Design: https://claude.ai/artifact/DdVq8kTFNM6jXXyRqkVZgH (ПК и телефон; данные на холсте выдуманы). Версия: 0.36.0.

## Вкладки

- **Отчёт месяца** — прежний `MonthlyReview` (итог месяца, календарь, XP, сферы, заметки). Новый дизайн отчёта с холста (радар, карточки сфер, «Важное и усилия») не перенесён.
- **Мои итоги** — `MyResults`, главный новый экран.
- **Динамика** — прежняя `Statistics` (XP по неделям/месяцам/годам, сравнение, Life Score).

## «Мои итоги»: 7 шагов

1. **Факты:** XP, задачи, активные дни, лучшая серия; быстрая отметка настроения и энергии 1–5, график и наблюдения.
2. **Планы прошлого месяца:** слова пользователя из поля «Что будет в следующем месяце» → «Сделано / Частично / Не вышло».
3. **Маленькие победы:** найдены по истории (серия, активные дни, задачи, цели, новый уровень сферы, рост XP). Ничего не выдумывается.
4. **Итоги по сферам** (девять): «Что удалось достичь», «Что не получилось», «Что будет в следующем месяце», «Если… то…», оценка сферы 1–10, динамика (рост / стабильно / просадка), «Превратить в задачу».
5. **Благодарность:** три строки.
6. **Три фокуса:** не больше трёх сфер, фокус выбирается из планов сфер.
7. **Оценка месяца:** 1–5 звёзд (это поле `mood` прежней заметки месяца), кнопка «Завершить итоги месяца».

За итоги XP, серии и штрафы не начисляются.

## Правила

- **План → задача.** У сферы кнопка «＋ Превратить в задачу на следующий месяц» (активна, когда план написан). Задача создаётся при завершении итогов через `saveCustomQuest`: срок — 1-е число следующего месяца, сложность «Сложный» (40 XP). Повторно задача не создаётся (`questId` запоминается). Задача попадает в «Мои задачи» → «Входящие» как обычная задача без цели.
- **Уверенность 1–10.** Ниже 7 предлагается шаг поменьше (`smallerStep`: пропорционально уменьшает километры, раз, дни; иначе «в два раза меньше»).
- **Мягкий режим.** Включается кнопкой «Тяжело сейчас?» или после оценки 1–2. Скрывает шаги 2–6; два вопроса («что помогло выдержать», «один маленький шаг») и «Закончить мягко». Шаг становится задачей «Простой» (10 XP) в первом выбранном фокусе, иначе в «Здоровье» — сфера назначена помощником.
- **Подсказки** с примерами у каждого поля; переключатель запоминается в `localStorage` (`pyl-results-hints`).
- **Настроение и энергия** — `moodCheckins[дата] = {mood, energy}`. График — от двух отметок, выводы — от шести: связь энергии с днями выполнения задач, самый тяжёлый и самый лучший день. Это наблюдения, а не причины.

## Хранение

- `GameState.monthlyReflections[месяц].review` (`MonthReview`, `src/keyResults.ts`) и `GameState.moodCheckins`. Оба поля необязательные, старые сохранения читаются без миграции.
- Проверка: `validReview`, `validMoodCheckins` в `stateValidation.ts`. Тексты по сферам — до 2000 знаков, короткие поля — до 200, название задачи — до 100.
- `firestore.rules` не менялся (состояние проверяется общим документом).
- Тесты: `tests/key-results.test.ts`, UI: `tests/key-results-ui.mjs` (`npm run test:key-results-ui`, снимки в `work/key-results/`).

## Не реализовано

Новый «Отчёт месяца» с холста; отдельное окно «Итог сферы»; «Важность сферы 1–5» и сравнение с усилиями; вставка итогов в историю сферы; уведомления-напоминания об отметках настроения.
