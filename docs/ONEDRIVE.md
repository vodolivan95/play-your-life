# Мой диск — подключение OneDrive

Раздел `#/drive` использует Microsoft Graph с разрешениями `User.Read` и `Files.ReadWrite`. Вход через MSAL Browser выполняет OAuth Authorization Code + PKCE. Токены находятся в памяти/`sessionStorage` браузера и не входят в игровой `GameState` или Firebase. Учётная запись Microsoft привязывается к текущему UID Firebase в рамках сессии. В гостевом режиме подключение недоступно. После выхода из Play Your Life сессия OneDrive остаётся в браузере, но привязка к иному UID не даёт разделу выбрать эту учётную запись. Для семейного устройства рекомендуется завершать сеанс браузера после работы.

## Настройка Microsoft Entra

1. Зарегистрируйте приложение в Microsoft Entra admin center → App registrations. Тип аккаунтов: личные Microsoft и организационные (если нужны оба типа).
2. В Authentication добавьте платформу **Single-page application** с URI `https://vodolivan95.github.io/play-your-life/`. Для разработки добавьте `http://localhost:5173/` (или точный адрес dev-сервера).
3. В API permissions добавьте делегированные Microsoft Graph `User.Read` и `Files.ReadWrite`. Для организаций администратор может требовать consent.
4. Скопируйте **Application (client) ID** в `VITE_MICROSOFT_CLIENT_ID`: для GitHub Pages добавьте его в **Settings → Secrets and variables → Actions → Variables**, для Vercel — в **Project Settings → Environment Variables** и повторно разверните проект, для локального запуска — в `.env.local`. Это публичный идентификатор SPA, не секрет. Клиентский секрет SPA не требуется и в Vite не помещается.
5. Запустите `npm ci` и `npm run dev`; войдите в Play Your Life и откройте «Мой диск».

## Поведение и границы

Основной вид — сетка с папками перед файлами; список доступен дополнительно. Содержимое, квота и поиск поступают из Graph. Каталоги загружаются постранично по 100 объектов; кнопка «Показать ещё» открывает следующую страницу. Поддерживаются создание папки, загрузка (до 4 МиБ целиком, крупнее — upload session), скачивание, переименование, перенос по ID папки, удаление с подтверждением, ссылки и локальный цвет папки. Цвет хранится отдельно по Firebase UID, drive ID и item ID. После очистки браузера цвет сбрасывается. Поиск Graph может по-разному работать в личном и рабочем OneDrive. Вкладка «Фотографии» показывает изображения текущей папки; общий альбом всего диска и сортировки требуют отдельной реализации.

Это браузерная интеграция без серверного хранилища refresh token. Ограничение модели: изоляция от других пользователей Play Your Life внутри одного браузерного профиля обеспечивается выбором связанного аккаунта, но строгая серверная изоляция требует отдельного серверного OAuth посредника с проверкой Firebase ID token и хранилищем зашифрованных токенов. Сейчас документы открываются в Microsoft 365 по `webUrl`; миниатюры запрашиваются при появлении файлов на экране. Встроенный просмотр требует следующего этапа. Кнопки на странице не создают фиктивные файлы.
