# Публикация через GitHub Pages

Адрес сайта после успешной публикации: https://vodolivan95.github.io/play-your-life/

Публикация уже настроена. Для принятой версии цели и этапов `be5fe44` сборка и публикация [прошли в Actions](https://github.com/vodolivan95/play-your-life/actions/runs/37837980615). После новых изменений проверяйте результат для соответствующего коммита актуального `main`.

## Один раз в GitHub

1. Сохраните изменения проекта в ветку `main` через Commit и Sync/Push в Codespaces. Если изменения в другой ветке, создайте Pull Request и нажмите Merge pull request.
2. Откройте репозиторий → Settings → Pages.
3. В разделе Build and deployment выберите Source → GitHub Actions.
4. После первого включения Pages дождитесь автоматической публикации очередного изменения `main`. Если первая публикация ранее завершилась ошибкой настройки Pages, повторите именно её. Для проверки доступа запускать новую публикацию не требуется.
5. Дождитесь зелёной галочки. Откройте адрес сайта выше.

После каждого изменения в `main` сайт обновляется автоматически. Если Actions ещё не разрешены для репозитория, включите их во вкладке Actions. Для приватных репозиториев доступность Pages зависит от тарифа GitHub.

## Как устроено

Существующая проверка `ci.yml` сохранена. Отдельный `pages.yml` устанавливает зависимости через npm ci, запускает тесты игровой логики и npm run check, загружает dist и публикует артефакт официальными GitHub Actions. Первое включение Pages требует действий владельца репозитория: токен GitHub Actions не имеет прав для создания сайта (Resource not accessible by integration). Один раз выберите Source → GitHub Actions вручную и повторите запуск. Доступ записи ограничен задачей публикации; используется временная OIDC-авторизация GitHub, дополнительные секреты не нужны.

При публикации VITE_BASE_PATH=/play-your-life/ задаёт корректные ссылки на ресурсы. При обычном npm run dev приложение работает от корня. Для локальной проверки опубликованной сборки:

```sh
VITE_BASE_PATH=/play-your-life/ npm run check
VITE_BASE_PATH=/play-your-life/ npm run preview
```

Откройте http://localhost:4173/play-your-life/. Цели и этапы используют адреса после `#`, например `#/goals/g/stages/s`; прямую ссылку можно обновить без серверных настроек SPA.

Исходники в GitHub, опубликованная сборка Pages и прогресс игрока сохраняются отдельно. Гостевая и демо-игра сохраняются локально для устройства и адреса сайта: данные localhost не переносятся автоматически на GitHub Pages. Личная игра вошедшего пользователя использует существующую синхронизацию Firebase при доступном сервисе и корректной авторизации. Публикация сайта сама по себе не переносит и не подтверждает сохранение пользовательских данных.
