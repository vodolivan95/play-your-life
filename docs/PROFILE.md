# Страница «Профиль»

Версия 0.44.0, ширина страницы и раздел «Настройки» — 0.61.0. Макет согласован на холстах Claude Design «Меню пользователя — новый дизайн»:
https://claude.ai/artifact/5QydEaHaDXMd8bqHPMULnr (тёмная и светлая тема, ПК и телефон, презентация в стиле Apple).

С 0.61.0 страница растянута на всю ширину `<main>` (у `.profile-page` убран собственный `max-width: 640px`) в веб- и мобильной версии — как остальные разделы приложения.

Экран открывается по `page === 'profile'` внутри `src/App.tsx` (блок `profile-page`, не отдельный компонент) и использует общие классы из `src/interface.css` + их автогенерированные тёмные варианты в `src/theme-dark.generated.css` (`npm run theme:dark`).

## Состав экрана

1. **Шапка (`profile-hero`)** — аватар, имя, звание, `LEVEL · XP`, полоса прогресса, кнопка настроек. Не менялась.
2. **Подсказка новому игроку (`profile-tip`)** — показывается, когда `state.xp === 0`, и скрывается кнопкой-крестиком (`profileTipDismissed`, локальный `useState`, не сохраняется между перезагрузками).
3. **Статистика (`profile-rewards`)** — Монеты, Серия, Достижения. У «Серии» под числом — семь точек (`streak-dots`), отмечающих активные дни за последнюю неделю по `state.activeDates`.
4. **Группы разделов** (новое, вместо одного плоского списка):
   - **Быстрый доступ** (`profile-quick-grid`, крупные плитки): Мои задачи (со счётчиком `profile-quick-badge`, та же формула, что у бокового меню — активные задачи на сегодня + входящие TickTick), Привычки, Цели, Сферы жизни.
   - **Прогресс** (`profile-menu`, список со стрелкой): План жизни, Дерево навыков, Достижения, Ключевые итоги.
   - **Система** (`profile-menu`): Магазин, Город.
4a. **Настройки** (`profile-menu profile-settings`, с 0.61.0) — переключатель светлой/тёмной темы (`ThemeSwitch`, тот же компонент, что и в боковом меню) и «Настройки персонажа» (имя, фото, аватар — открывает `ProfileEditor` тем же модальным окном, что и раньше). Перенесено из группы «Система», где раньше была только ссылка на «Настройки персонажа» без самой темы.
5. Ниже без изменений: подключение TickTick и «Скачать копию» / восстановление.

Состав разделов берётся из `src/navigation.ts` (один источник для бокового меню, мобильной панели и этой страницы) — группировка переопределена только локально в `App.tsx`, сам `navigation.ts` не менялся.

## Что из макета не перенесено

Макет на холсте показывает ещё несколько пунктов, которых нет в игре как отдельных функций: «Друзья и рейтинг», «Журнал дня», «Поддержка», «Поделиться профилем» и отдельная «Мои награды» (кроме существующего «Магазин»). Их не стали добавлять в разметку — по правилу `AGENTS.md` не реализовывать экраны без отдельного задания; эти пункты ждут нового ТЗ.
