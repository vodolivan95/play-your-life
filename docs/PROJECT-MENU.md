# Меню проекта 0.85.0

Запрос и согласование: [#334](https://github.com/vodolivan95/play-your-life/issues/334). [Макет](design/project-menu-approved.png). Цвета и геометрия используют StageScreen. Вкладки проекта сохранены, добавлены «Материалы проекта». Этапы показаны снизу вверх без перестановки самих данных. Перенос задач использует существующий TaskReorderList, включая touch и клавиатуру.

Следующий шаг использует сохранённую focusSession. До запуска обратного отсчёта нет. Пауза/продолжение/завершение работают через общий движок фокуса; завершение сессии не выполняет задачу и не выдаёт XP. Даты выполнения берутся из tasksCalendar, перенос сдвигает интервал с сохранением времени и отдельного дедлайна.

Goal.materials и notesStarred — необязательные поля, старые сохранения совместимы. До 50 материалов, до 5000 символов в заметке и 100000 суммарно. Файл до 20 МБ хранится в IndexedDB по ключу аккаунт/проект/материал. Сохранение игры содержит только метаданные. Бинарные файлы не входят в облачную синхронизацию/резервную копию игры; очистка данных браузера удаляет локальные файлы. OneDrive пока не подключён. Избранные заметки и файлы отображаются первыми справа, на телефоне — под основным содержимым.

Проверки: tests/project-materials.test.ts и tests/goals-ui.mjs (1440/768/390/360, мобильное touch-управление). Проверки выполняются на тестовых данных, не на персональных данных пользователя.
