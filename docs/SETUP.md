# Работа с телефона

Репозиторий: https://github.com/vodolivan95/play-your-life
Имя окружения: PLAY YOUR LIFE.

1. Откройте репозиторий → Code → Codespaces → Create codespace on main.
2. Дождитесь установки зависимостей. На телефон устанавливать программы не нужно.
3. Выполните `npm run dev` в терминале браузерного редактора.
4. Во вкладке Ports откройте порт 5173, оставив доступ Private.
5. Пустая страница ожидаема: сейчас настроено только окружение.
6. После изменений выполните `npm run check`.
7. Сохраните изменения через Source Control: Commit, затем Sync/Push.

Первый запуск создаст package-lock.json. Добавьте его в первый коммит из Codespaces:
он закрепит точные версии зависимостей. Далее окружение будет использовать npm ci.

Если на телефоне не видны кнопки, включите «Версия для ПК» в браузере.
Codespaces имеет лимиты использования, зависящие от аккаунта GitHub.
После работы останавливайте окружение: https://github.com/codespaces
Не отправляйте пароли или токены в чат и не сохраняйте секреты в репозиторий.
