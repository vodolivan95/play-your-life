# Работа с телефона — V0.1

1. Откройте репозиторий https://github.com/vodolivan95/play-your-life → Code → Codespaces.
2. Выберите ветку с реализованной V0.1 и создайте Codespace. Дождитесь установки зависимостей.
3. Выполните `npm run dev` в терминале браузерного редактора.
4. Во вкладке Ports откройте порт 5173. Доступ можно оставить Private.
5. Откроется PLAY YOUR LIFE с демоданными. Выполняйте квесты, создавайте цели и меняйте Life Score.
6. После изменений кода выполните `npm run check`. Команда проверяет ESLint, игровую логику, TypeScript и сборку.
7. Сохраните изменения через Source Control: Commit, затем Sync/Push.

`package-lock.json` сохранён. Используйте `npm ci` для воспроизводимой установки.

Прогресс хранится в браузере и привязан к адресу приложения. Другой браузер или другой адрес не увидит прежние данные. Удаление данных сайта удалит прогресс. Серверной синхронизации нет.

Если на телефоне не видны кнопки GitHub, включите «Версия для ПК» в браузере.
После работы останавливайте Codespace на https://github.com/codespaces.
Не сохраняйте пароли и токены в репозиторий.
