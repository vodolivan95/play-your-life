# Сферы и проекты

В разделе «Сферы жизни» добавлена горизонтальная полоса всех девяти существующих сфер. У каждой есть иллюстрация собственного здания в тропическом городе, текущий Life Score и цветовая шкала. Полоса прокручивается на телефоне и компьютере.

Внутри каждой сферы по умолчанию открываются «Проекты». Проекты используют существующие цели: прогресс, этапы, задачи, сроки и награды сохраняются. Карточка открывает действующий редактор плана цели. Разделы задач, целей, истории и статистики остаются доступны.

Идеи проектов отличаются для каждой сферы. Они не добавляются автоматически. Кнопка «Добавить в мои проекты» создаёт проект только в выбранной сфере, без готовых задач и без начисления XP. Открой его, чтобы настроить срок, этапы и задачи. При совпадении названия кнопка отключается.

Создание проекта не отправляет его в TickTick. Существующие правила синхронизации конкретных подзадач сохраняются.

Проверка: `npm run check`, 59 существующих тестов и браузерная проверка девяти сфер на ширинах 320–1920 px. Проверены сохранность данных, создание проекта в нужной сфере и открытие его плана.
