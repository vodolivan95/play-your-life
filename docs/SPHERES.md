# Сферы жизни

Раздел по согласованному макету «Сферы жизни — новый дизайн» (Claude Design, 11 октября 2026). Работает в светлой и тёмной теме, на компьютере и телефоне.

## Обзор

- Верхний блок без изменений: «Твой баланс жизни», паутина «Баланс сфер жизни», «Фокус развития». Подписи сфер в паутине открывают окно сферы.
- «Мои сферы» — девять карточек районов: здание, уровень, метка «Сильная / В пути / Внимание», звание, XP до следующего уровня, проекты в работе, задачи на сегодня, дни подряд. Кнопки «Открыть район →» и «+» (новое задание в этой сфере). Нажатие на фото открывает окно сферы.
- Фильтр: «Все», «Есть задачи», «Нужно внимание», «Сильные». Порядок: по порядку, сначала отстающие, сначала сильные.
- «Следующие шаги по сферам» — ближайшие задачи на сегодня (их можно отметить сразу), «XP за неделю по сферам» — сумма XP за последние 7 дней.

## Окно сферы

Здание, уровень, отставание или опережение среднего уровня, проекты, задачи сегодня, дни без действий, XP до нового уровня, идея проекта для быстрого старта и кнопки «Открыть район», «+ Новое задание», «Войти в здание». Закрывается крестиком, по фону и Esc.

## Открытая сфера

Обложка района: кольцо уровня, звание, XP, всего XP, дни подряд, проекты в работе, метка положения, кнопки «+ Новое задание», «+ Новый проект», «Войти в здание». Вкладки:

- **Обзор** — до двух проектов района (метка «Главный квест месяца», прогресс, следующий шаг, награда), задачи на сегодня, XP по неделям (8 недель), три навыка из Skill Tree, сколько XP до следующего уровня, последние события.
- **Проекты** — активные и завершённые проекты и идеи проектов (как раньше, в оформлении темы).
- **Задачи**, **История**, **Статистика** — как раньше.
- **Навыки** — все навыки сферы из Skill Tree со статусом и уровнем.

Прежняя вкладка «Цели» убрана: те же проекты показаны в «Проектах».

## Правила расчёта (`src/sphereDetails.ts`)

- Метка: «Сильная», если уровень сферы выше среднего уровня активных сфер на 1 и больше; «Внимание» — ниже на 1 и больше; иначе «В пути». В новой игре у всех «В пути».
- Звание по уровню: Новичок (0–2), Ученик (3–9), Практик (10–24), Мастер (25–49), Эксперт (50–99), Легенда района (100).
- Дни подряд — дни с событиями XP этой сферы до сегодня или вчера включительно. Награды за уровень района не добавлялись.
