# Уровни сфер

Сфера развивается от 0 до 100. Источник уровня — накопленный XP этой сферы. Константы и расчёт находятся в src/sphereProgress.ts: уровень равен целой части XP / 200 с ограничением 100. Действие добавляет только предусмотренную награду.

Карточки показывают уровень отдельно от XP внутри текущего уровня. При максимальном уровне накопленный XP, включая избыток, сохраняется. Уровень персонажа рассчитывается отдельно.

Средний баланс вычисляется по активным сферам: сфера активна, если имеет XP, проект или задачу. При отсутствии активных сфер среднее равно нулю. Сильная и слабая сферы определяются среди активных, разрыв — разность их уровней. Диаграммы используют шкалу 0–100.

## Совместимость сохранений

Миграция добавляет маркер xp-levels-100-v1 и сохраняет XP, проекты, задачи, историю, монеты и оформление города. Она идемпотентна. Старые поля самооценки сохраняются для совместимости с резервными копиями, но не определяют уровень. Самооценка не превращается в заработанный XP. Ранее полученное достижение сохраняется. Старые резервные копии без маркера принимаются и адаптируются при загрузке.

Новые игроки начинают с нулевого XP во всех сферах. Оформление здания и изменение другой сферы не устанавливают уровень этой сферы.
