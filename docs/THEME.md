# Светлая и тёмная тема

Тема одна на всё приложение. Её меняет любой переключатель «Тёмная / Светлая»: в левом меню, в шторке «Ещё» на телефоне и в Skill Tree. По умолчанию — тёмная; выбор хранится на устройстве (`localStorage`, ключ `play-your-life-home-theme`).

## Как устроено

- `src/menuTheme.ts` хранит тему и ставит её на `<html data-theme="dark|light">`, а также меняет цвет строки браузера (`theme-color`).
- Главная, меню и Skill Tree оформлены вручную по своим макетам (`data-theme` на компоненте).
- Остальные разделы используют светлые стили как основу. Тёмные цвета для них создаёт `scripts/build-dark-theme.mjs` → `src/theme-dark.generated.css`: те же селекторы под `:root[data-theme="dark"]`, светлые фоны становятся тёмно-синими, тёмный текст — светлым, яркие кнопки и иллюстрации не меняются.
- Ручные уточнения тёмной темы (фон страницы, верхняя панель, поля ввода, окна) — `src/theme-dark.css`.

## Переключатели в стиле Apple (0.25.2)

В тёмной теме сегментные переключатели (`.tabs`, `.pyl-theme`, `.lpm-seg`, `.hb-seg`, `.sph-segment`, `.account-tabs`, вкладки магазина) рисует `src/apple-switch.css`, подключённый последним: дорожка `rgba(118,118,128,.24)` со стеклом, активный сегмент `#636366` с мягкой тенью, белый текст, плавная смена за 0,28 с, фокус — синее кольцо. Новый переключатель добавляйте в список селекторов этого файла. Скользящей «пилюли» нет: активный сегмент меняет фон.

## После изменения стилей

`npm run build` пересоздаёт тёмные стили автоматически; вручную — `npm run theme:dark`. Новый файл стилей страницы добавьте в список `sources` в скрипте.

Проверка: `npm run test:theme-ui` проходит все 12 разделов на компьютере и основные на телефоне в обеих темах и сохраняет снимки в `work/theme/`.
