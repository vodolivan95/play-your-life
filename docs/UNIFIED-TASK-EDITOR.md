## Согласованный вид

Источник — приложенный пользователем в чате мобильный макет из трёх областей «Главное / Планирование / Дополнительно» и исходные снимки TaskWindow. Исходный согласованный [макет сохранён в репозитории](design/task-editor-approved.png). Эти три области обозначают продолжение одного окна; существующие вкладки «Планирование / Описание / Вложения / Заметки / История» сохранены.

Сохранены тёмно-синие поверхности, голубые границы, фиолетовая активная вкладка, кольцо XP, проект/этап, прогноз цели, статус и первоначальные иконки сфер. На телефоне второстепенные действия доступны через «…», две основные кнопки закреплены снизу. Значения, фотографии и проценты из макета не подставляются в пользовательские данные.

## Точки входа и сохранение

- Главная, сферы, «Мои задачи», проект и этап: `QuestWizard → TaskCreationForm → TaskWindow`.
- Планировщик и расширенное редактирование: `TaskForm → TaskCreationForm → TaskWindow`.
- Быстрая задача в «Моём плане»: введённое название передаётся в тот же редактор; данные записываются после подтверждения.
- Входящие TickTick, включая переход из календаря: `TickTickInbox → TaskCreationForm → TaskWindow`.
- Открытие существующей задачи: исходный `TaskWindow`.

Новая задача редактируется в изолированном черновике: отмена не создаёт задачу и не запускает синхронизацию. Создание проекта/этапа по явному действию в разборе входящих сохраняет соответствующий проект/этап отдельно. У существующих задач параметры сохраняются сразу; название и описание — кнопкой «Сохранить», как прежде.

Валидация общая для создания, редактора и импорта. Новые поля необязательны и проходят существующую проверку сохранения. Синхронизация может принять плановую дату TickTick позже локального дедлайна: локальный дедлайн не удаляется и обмен не блокируется; при ручном изменении сроков предлагается согласовать их.

## Практические ограничения

- Contact Picker зависит от поддержки браузера и разрешения пользователя; при отсутствии API доступен ручной ввод. Тест проверяет контракт с подставным API, а не доступ к телефонной книге устройства.
- Напоминания — внутри открытой страницы, без фонового push или гарантии при закрытом/усыплённом приложении. После возвращения учитывается окно последних пяти минут; после перезагрузки в этом окне возможно повторное уведомление.
- Файл ограничен 250 000 байт; до 10 вложений, общий объём URL/dataURL — 350 000 символов. Крупное видео/документы добавляются ссылкой. Облачное файловое хранилище не подключалось.
- API TickTick в существующей интеграции не переносит контакты, локальные вложения/обложку, мотивацию, заметки нового формата, локальные напоминания и физический дедлайн. Получение фотографий из закрытых вложений TickTick не реализовано. Эти поля сохраняются только в игре.
- Сетевая отрисовка Яндекс Карт зависит от доступности сервиса. UI-проверка проверяет адрес iframe и маршрут; внешний сервис в тесте заблокирован.
- Публичный Issue отклонён автоматической проверкой из-за публикации подробностей в открытом репозитории. Ветка, PR, GitHub Actions и production пока не опубликованы/не проверены; для этого запрашивается отдельное разрешение после подготовки кода.
