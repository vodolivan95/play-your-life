# PLAY YOUR LIFE V0.1

Кликабельный прототип на React + TypeScript + Vite. Данные сохраняются в localStorage текущего браузера. Авторизации и сервера нет.

## Игровые правила

- Выполнение квеста начисляет XP игроку и выбранной сфере. Повторное выполнение заблокировано. Монеты: округлённый вверх XP / 5.
- Уровень игрока начинается с 12 при 2450 XP. Следующий — при 3000 XP, далее каждые 550 XP. Уровни сфер — каждые 200 XP.
- Life Score — оценка 0–9. При первом улучшении бонус равен разнице оценок × коэффициент. Чтобы исключить фарм через снижение и восстановление оценки, бонус начисляется только за рост выше максимальной ранее достигнутой оценки. При снижении XP не отнимается.
- Коэффициенты и награды заданы централизованно в `src/game.ts`.
- Серия учитывает календарные дни выполнения квестов в часовом поясе устройства. Несколько квестов в день не увеличивают серию. Пропуск дня сбрасывает её. Бонус начисляется при выполнении квеста на соответствующем рубеже и относится к его сфере.
- Большие цели: награда 100–500 XP при достижении целевого значения. Повторное получение награды исключено, даже если прогресс уменьшить.
- Общий Life Score — среднее девяти сфер. Дерево навыков — визуальный прототип; узлы открываются согласно уровню сферы.
- Начальные XP и уровни — демонстрационные, активность и история начинают накапливаться после действий пользователя. Квесты одноразовые, автоматического создания ежедневных повторов нет.

## Экраны

Главная, девять сфер с деталями и историей, квесты, цели, Skill Tree, достижения. На мобильном — нижняя навигация, на больших экранах — боковая панель и ограниченная ширина контента.

## Проверка

`npm run check` запускает ESLint, TypeScript и production-сборку. `node --experimental-strip-types --test tests/game.test.ts` проверяет начисление XP, защиту от повторных наград и календарную логику серий.

Если браузер блокирует localStorage, приложение показывает сообщение: прогресс доступен только до закрытия страницы. Очистка данных браузера удаляет прогресс.
