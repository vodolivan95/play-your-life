# V0.2 — личная игра

На первом запуске можно выбрать деморежим или создать личную игру. Настройка состоит из трёх шагов: имя и аватар, начальная оценка девяти сфер (0–9), главная цель и её целевое значение.

Личная игра начинает с уровня 1, нулевого XP и монет. Квесты добавляет пользователь, цель стартует с нулевого прогресса. Первоначальные оценки не начисляют XP, они задают исходный максимум для защиты от фарма. За первую цель назначена награда 200 XP.

Уровни личного игрока повышаются каждые 200 XP. Полоса показывает прогресс внутри текущего уровня, а общий XP указан отдельно. Уровни сфер и остальные игровые правила V0.1 сохранены.

## Профиль и главная цель

Нажмите на аватар в верхней панели (на desktop также на имя в боковой панели), чтобы изменить имя или аватар. Это сохраняет все квесты, цели, XP, оценки и историю.

В разделе «Цели» кнопка «Сделать главной» выбирает цель для главного экрана. Выбор сохраняется при перезагрузке. Достигнутая цель остаётся главной до выбора другой.

## Сохранения V0.1

Данные остаются в прежнем ключе localStorage. Старые сохранения автоматически получают демопрофиль, сохраняя прежние уровни, XP, квесты, серии, награды, оценки и историю. Настройка при обновлении не запускается принудительно.

Из деморежима можно начать собственную игру через баннер «Начать» или профиль. Текущие демоданные заменяются только после завершения настройки и подтверждения флажком. Отмена сохраняет прежнюю игру. Уже личная игра не предлагает повторную настройку стартовых оценок.

Профиль и прогресс сохраняются только в браузере этого устройства. Обновление сайта сохраняет прогресс; очистка браузерных данных или другое устройство не переносит его автоматически.

## Проверки

`npm run check` и `node --experimental-strip-types --test tests/*.test.ts`. Workflow Pages запускает все тесты перед публикацией. Браузерная проверка включает первый запуск, деморежим, личную игру, редактирование профиля, выбор главной цели, перезагрузку и миграцию V0.1.
