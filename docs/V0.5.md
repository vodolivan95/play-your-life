# V0.5 — светлый игровой интерфейс

Все разделы оформлены в едином стиле по предоставленному образцу: белые карточки на светло-голубом фоне, яркие синие кнопки, мягкие тени, цветные игровые иконки и компактные строки действий.

На телефоне снизу пять вкладок: **Главная, Цели, Квесты, Статистика, Профиль**. В профиле доступны сферы жизни, план жизни, итоги месяца, Skill Tree, достижения и настройки персонажа. На планшете и desktop — боковое меню и ограниченная ширина контента.

- Главная: персонаж, уровень, XP, монеты, серия, достижения, главная цель, сегодняшние квесты. На телефоне главная компактная, как в образце; на desktop квесты и сферы размещены рядом, ниже — недельный прогресс.
- Сферы: компактная сетка карточек. Внутри — уровень, XP, круг Life Score, коэффициент, изменение оценки и вкладки квестов, целей, истории и статистики. Изменение оценки открывается отдельно.
- Цели: фильтры активных, достигнутых и всех целей; раскрываемые прогресс и сроки. План цели, этапы, конкретные задачи, даты и награды сохранены.
- Создание квеста: отдельный экран на телефоне, название, сфера с игровой иконкой, описание, пять карточек сложности и предварительный просмотр награды XP. Шаблоны заполняют форму, создание не начисляет XP.
- Skill Tree: связанная карта девяти сфер и отдельный вид навыков с открытыми и заблокированными узлами.
- Достижения: компактные строки и фильтры открытых/ожидаемых наград.
- Статистика: неделя, месяц и год; XP по дням/месяцам, выполненные действия, серия и вклад сфер. Используется история реальных действий, без вымышленных графиков. Старый XP без событий не распределяется задним числом.
- Профиль: аватар, уровень, награды и меню всех разделов. В выборе аватара добавлен личный персонаж в игровом стиле; он выбран по умолчанию для новых профилей. Ранее выбранные аватары и остальные данные сохраняются.

Существующие локальные сохранения и правила XP сохранены. React + TypeScript + Vite, devcontainer и автоматические GitHub Actions продолжают использовать прежнюю конфигурацию.

Подготовлено сопоставление сфер с существующими списками TickTick: «Английский» → «Английский язык», остальные названия совпадают. «Работа» не привязана, поскольку такой сферы пока нет. Только конкретные подзадачи целей предназначены для обмена. Живая авторизация и синхронизация аккаунта остаются отдельным следующим этапом; текущие проверки API выполняются с имитацией сервера.

Проверки: `npm run check`, тесты игровой логики и интеграции; браузерные проверки всех разделов при 13 ширинах от 320 до 2560 px, создания задач, этапов и целей, однократного начисления XP, сохранений, аватара, экспорта календаря и сопоставления списков с имитацией API. Публикация — прежний workflow GitHub Pages.

Уточнение по образцу: единые цветные векторные иконки сфер, компактные строки целей, шкалы прогресса достижений, расположение веток Skill Tree и полноэкранная форма квеста. Числа отражают сохранённый прогресс пользователя, а не значения с изображения.

Исправлена смена аватара в личной игре: фотография в приветственной строке могла расширять страницу из-за отсутствия собственного ограниченного контейнера. `Avatar` теперь обрезает изображение внутри круга, а размер задаётся контейнером, независимо от исходного PNG. Проверены выбор фотографии в личном режиме, окно выбора, приветствие, профиль и повторная загрузка при восьми ширинах 320–2560 px; цели, XP и остальные поля прогресса сохраняются.
