# Мой план на неделю

Согласованный холст Codex «Мой план на неделю» описан в [задаче #330](https://github.com/vodolivan95/play-your-life/issues/330).

- Открой «Мои задачи → Мой план → Неделя». Переключай недели стрелками. Кнопка «Список» открывает прежние представления и фильтры.
- Три результата редактируются над доской. Привязку к результату можно выбрать в карточке задачи. Прогресс считают по связанным задачам. Если задача переехала, связь с исходным результатом сохраняется.
- День выполнения и дедлайн независимы. Перенос за дедлайн предупреждает и требует подтверждения. Задачи на доске отнесены к дням по той же плановой дате, что и в списке.
- Справа свободное время рассчитывается по известным оценкам после вычета 8 часов сна за день. Бюджет плана отдельно следует выбранным дням и резерву. Задачи без оценки отмечаются рядом со сводкой.
- «Итоги недели» открывают компактную сводку выбранной недели. Полный недельный обзор доступен в режиме «Список». Оставшуюся задачу можно перенести на любой день следующей недели или отправить в «Без даты». История использует события переноса плана. Сохранённые обзоры сохраняют прежние числовые итоги, списки задач показывают их текущее состояние.

Результаты хранятся в необязательном поле `weekPlanOutcomes` сохранения игры. Старое сохранение открывается с пустыми результатами. Снятие плановой даты сохраняет дедлайн.
