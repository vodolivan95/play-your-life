# PLAY YOUR LIFE 2.0 — план и модель данных

ТЗ: «PLAY YOUR LIFE 2.0. Модернизация системы управления личной и совместной жизнью» (19.11.2026).
Решения Александра: вложения — сжатые прямо в Firestore (без Firebase Storage); слоган «Твоя жизнь. Наши общие моменты.»; работа по этапам.

## Аудит (этап 1)
- Авторизация: Firebase Auth (`src/firebaseClient.ts`, `src/AccountRoot.tsx`). Гостевой вход без пароля — только локальная игра, общего пространства в нём нет.
- Firestore до 2.0: только личные данные `players/{uid}` (+ `events`, `months`, `images`). Общих коллекций не было.
- Firebase Storage не подключён. Правила проверяются эмулятором в CI (`tests/firebase-rules.test.mjs`, `tests/shared-space-rules.test.mjs`).
- Маршруты — hash (`#goals`, `#/tasks/…`, `#profile`). Новые: `#our/chat|calendar|places|meetings`, приглашение `#our/join/КОД`.

## Сущности
| Сущность | Где | Статус |
|---|---|---|
| Совместное пространство, участники | `spaces/{id}`: `name, ownerId, memberIds[], members{uid:{name,joinedAt}}` | этап 1 ✅ |
| Приглашение | `spaceInvites/{КОД}`: `spaceId, createdBy, createdAt, expiresAt` (7 дней) | этап 1 ✅ |
| Группы, сообщения, договорённости, итоги | `spaces/{id}/groups`, `…/groups/{g}/messages`, `…/agreements` | этап 2 |
| События, статусы участников, обсуждение | `spaces/{id}/events/{e}` (`rsvp{uid:…}`), `…/events/{e}/comments` | этап 3 |
| Места, предложения, комментарии | `spaces/{id}/places`, `…/proposals/{p}/comments` | этап 4 |
| Собрания, вопросы, решения | `spaces/{id}/meetings`, `…/questions`, `…/decisions` | этап 5 |
| Уведомления | `spaces/{id}/notifications/{uid}/items` | этапы 2–5 |

Каждый общий объект — один документ с одним id внутри пространства (ТЗ 12.3); копий в аккаунтах нет. Личный документ `players/{uid}` второму участнику по-прежнему закрыт.

## Права (firestore.rules)
- Пространство читает и меняет только участник из `memberIds`. Создать можно только своё (`s_<uid>`, один участник) — повторное создание не плодит копий.
- Вступить — только по действующему коду из `spaceInvites`, пока участников меньше 2; при вступлении меняются лишь `memberIds` (+ себя), своя запись `members`, `joinCode`, `updatedAt`.
- Участник меняет только своё имя; удалить пространство или исключить другого нельзя.
- Код приглашения: прочитать можно, только зная код (список запрещён); создать — участник пространства, срок ≤ 8 дней.
