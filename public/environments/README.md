# Sport skyline

Три панорамы созданного города получены генератором изображений для этого проекта. Пользовательские референсы интерьеров не включены. Применяются только к удаленной плоскости за остеклением; сама комната — WebGL 3D.

sport-city.jpg — SUNSET; sport-city-day.jpg — DAY; sport-city-night.jpg — NIGHT. JPEG ~2K. Не являются HDR источниками освещения: свет и отражения создаются отдельным RoomLighting / Environment.
